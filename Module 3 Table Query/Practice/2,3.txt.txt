Composite Primary Key: A composite primary key is a primary key made up of two or more columns that together uniquely identify each row in a table.

বাংলায়: যখন দুই বা ততোধিক Column একসাথে মিলে একটি Row-কে Unique ভাবে Identify করে, তখন তাকে Composite Primary Key বলে।
Example (MySQL)
ex:
CREATE TABLE Enrollment (
    StudentID INT,
    CourseID INT,
    EnrollDate DATE,
    PRIMARY KEY (StudentID, CourseID)
);

SELECT * FROM Student
