– 3. Differences Between Data and Information:


Data:
Definition: Data is a collection of raw facts and it has no specific meanings.
Data is unrecognized.
Data is used as input.
Difficult to understand.
Ex:
	Data: Name, 10, 90, Mark, Mehadi, Roll


Information:
1.Defination: Information is process data it has useful meaning.
2. Information is organized.
3.Information is used as output.
4.Esey to understand.
Ex:
	Info: Name: Mehadi, Roll: 10, Mark: 90

– 4. SQL Safe Update:

In MySQL, update and delete query may not execute because safe update mode is automatically enabled.

How:
Use set sql_safe_updates=0;
For disable safe update mode to delete or update query. 
And use set sql_safe_updates=1;
To enable safe update mode.
